# Test scores and written responses

Custom practice uses the stated +4 correct, −1 incorrect, 0 unanswered policy unless a stored question-specific policy applies. Numerical grading supports finite decimal/scientific values and compatible unit conversion; multiple-choice grading requires an exact match under the default policy.

Free responses are not assigned an automatic grade. Tests show an **automatically graded subtotal** that excludes free-response questions and other responses requiring human review from both numerator and denominator. A test with five correct automatic questions and one ungraded written response therefore shows **20/20**, with the written response separately awaiting self-review. A test containing only written questions shows no automatic numerical score, rather than 0%.

New submissions persist this automatic subtotal. Previous stored scores are immutable: if an older record included ungraded questions in its denominator, the result view preserves that historical total, labels it provisional, and separately displays the automatic subtotal derived from its original question/attempt snapshots. Self-review does not silently generate an assessed grade or mastery evidence.
